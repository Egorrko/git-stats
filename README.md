# git-stats

Локальный дашборд статистики git-репозитория: кто, когда и сколько коммитил.

Один Python-файл и одна HTML-страница. Зависимостей нет (нужны только `python3` и `git`), интернет не нужен, данные не покидают машину. Сервер слушает только `127.0.0.1` и лишь читает историю через `git log --numstat`.

## Запуск

```sh
git clone https://github.com/Egorrko/git-stats.git
cd git-stats
python3 gitstats.py ~/code/some-repo
```

Браузер откроется сам. Флаги:

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `путь` | текущая папка | репозиторий, который откроется первым |
| `--roots` | `~/my,~/Work` | где искать репозитории для выпадающего списка (через запятую, глубина до 4) |
| `--port` | `8765` | порт; если занят, берётся следующий свободный |
| `--no-open` | — | не открывать браузер |

Удобно положить ссылку в `PATH`:

```sh
ln -s "$PWD/gitstats.py" ~/.local/bin/gitstats
gitstats --roots ~/code
```

## Что показывает

- сравнение авторов: коммиты, добавлено/удалено строк, активные дни, типичный размер коммита;
- «гонку» авторов во времени;
- коммиты и строки по неделям/месяцам, рост кода нарастающим итогом;
- когда коммитят (день недели × час) и календарь активности;
- языки и папки, где больше всего кода;
- самые большие коммиты.

Фильтры: ветка, период, авторы, только код или только доки, исключения файлов по шаблонам. Можно отсечь коммиты другой ветки (например, апстрима форка), чтобы считать только свою работу. Учитываются `Co-authored-by`, ботов (dependabot и т.п.) можно скрыть. Любой график выгружается в PNG или таблицу, а кнопка «Сводка PNG» собирает картинку целиком.

## Настройки по репозиторию (необязательно)

Чтобы не выставлять фильтры каждый раз, положи рядом со скриптом `repos.json`. Пример лежит в [`repos.example.json`](repos.example.json):

```json
{
  "~/code/my-project": {
    "base": "origin/main",
    "authors": ["Your Name", "teammate"],
    "excludes": ["*.lock", "dist/", "# строки с # — комментарии"]
  }
}
```

- `base` — ветка, коммиты которой не считаются;
- `authors` — авторы, выбранные по умолчанию;
- `excludes` — шаблоны файлов, которые не считаются в строках.

`repos.json` внесён в `.gitignore`, так что личные настройки в репозиторий не попадут.
